What changed. The tree no longer starts with the generated source id twice; the source is a picker in the toolbar and the tree starts at objects. Each object row carries the marks of the treatments it contains, so a table's shape is readable before it is expanded. Declarations that matter show inline as chips — the domain, the timezone — so a reader sees them without opening anything. The declaration panel is a side panel beside the tree rather than a form above it, and each declaration is one line closed: name, value, provenance. A declaration that does not apply to this type says so and does not offer an input. The one warning is on the one dangerous change.
