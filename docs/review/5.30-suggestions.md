`/projects/:projectId/relationship-suggestions`.

17px treatment marks with pointer tooltips and visible treatment names,
current exposed types and domain provenance, separate query/explain demand,
seven UTC calendar-day trends, explicit existing/new domain choice cards,

absolute timestamps still follow display preferences. The backend reads only
catalogue, entitlement and attempt metadata; it does not read source values.

the same stored field used by Entitlements' member API, plus `columnName` from

stale-membership check; disclosure does not change the submitted members.

selection does not change geometry. No master stylesheet change is needed.
