# Shared form controls — approved replacement

The row-editor-only proposal is superseded by the shared `.inp` / `.sel`
pattern in `docs/opintel-master.css`, documented with default, focus, disabled
and invalid examples in `docs/visual-language.html`. There is no dark palette.

The base input geometry, typography, padding and focus ring are unchanged.
The native select adds an SVG background chevron and its right-side clearance,
with width supplied by its container. Disabled and invalid states are shared.
The SVG data URI contains the fixed ink hex by explicit decision: its fill must
match computed `--ink`, enforced by the control conformance checker. No wrapper,
extra SVG element, runtime generation or pointer-event rule is used.

The predicate builder uses the shared controls in equal flexible columns and
stacks them full-width below the existing 599px breakpoint. Its Column,
Operator and Value header remains visible. Native accessible names reference
those headers plus the condition number. AND/OR and parenthesis markers use the
existing chip patterns. The select is native at every viewport.

Validation: affected-route conformance first, then `check` once and `check:ui`
once if green. Review captures go to `tmp/review/`; no baseline changes.

## Measured controls and focused verification

Chromium initially gave native selects 35px and inputs 36px despite the shared
font and padding. The initial shared 18px line-height changed `.inp`'s computed value from
`normal`, shifting Activity's Agent placeholder. That regression is corrected:
only `.sel` states 18px; `.inp` retains its original computed styles.
Both still measure 36px high in the builder. At 390 they each
fill 216px of editor content. At 900 their outer widths are 183 / 183 / 162px;
at 1440, 363 / 363 / 342px. Flex allocates equal content space; selects also
carry the specified extra chevron padding.

The affected ten functional/conformance scenarios passed with zero findings;
the three builder scenarios then passed again after the line-height correction,
with exact 36px height assertions and zero findings. The native-label setup uses
the combobox role and its exact accessible name, assembled from the visible
header plus condition number. No conformance exception was introduced.

Twenty-one review PNGs and capture metadata are under `tmp/review/`, prefixed
`row-2b-`, for builder valid/refused, preview rows/aggregate-only, object
inherited/overridden, pool override editor and receipt link at all three widths.
These are review artifacts, not baselines.
