## How to use this register

This is the status authority for the items below. It records the read-only Phase 1 findings against `073cf74`; this documentation pass did not re-verify code, run tests or run the gate. IMPLEMENTED is source status, not a new validation claim. Evidence line numbers are those recorded at that revision; installed SDK evidence refers to pinned 2.0.6. Blocking dependencies describe remaining prerequisites, not newly approved implementation designs or delivery commitments.

Passages explicitly labelled as history — including “before 5.37” and “Before this approval” — are not current behavior. The action-acknowledgment audit's early tables are a preserved before-state; its corrections are recorded at `docs/review/action-acknowledgment-audit.md:98–143`. Neither should be converted back into open work by reading the earlier passage alone.

DELIBERATELY DEFERRED means retained future work subject to its recorded scope/decision. CANCELLED means no pending work: retired pixel comparisons and retired browser scenarios must not re-enter the backlog. Historical evidence remains preserved, including unexplained failures. XQ-DEPENDENT explicitly identifies an external provider prerequisite; a planned challenge also has a separate live-XQ verification dependency.
