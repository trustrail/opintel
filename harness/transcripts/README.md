# Transcripts

Dated Markdown transcripts are intentionally tracked. Run a behaviour, read
its responses, fill its blank reader verdicts and commit the transcript.
Never replace a past transcript: later runs produce new dated files. Compare
corresponding case sections with a normal diff. Request ids, evidence ids,
timestamps and tokens are preserved; they can change without a wording change.

No live run is supplied with the initial harness. A fabricated or mock response
must not be committed here as if it came from Opintel.
